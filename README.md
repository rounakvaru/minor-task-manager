# Task Manager Web Application

## 📄 Project Description
The **Task Manager Web Application** is a simple, browser-based tool that helps users manage their daily tasks. Users can add new tasks, view them in a list, mark them as completed, and delete tasks they no longer need — all without reloading the page. This project was built as **Minor Project 2** to demonstrate core front-end web development skills, including DOM manipulation and event handling using vanilla JavaScript.

## 🛠️ Technologies Used
- **HTML5** – Page structure and content
- **CSS3** – Styling and responsive layout
- **JavaScript (Vanilla)** – Dynamic behavior and DOM manipulation

## ✅ Features
- Add new tasks using the input field or by pressing Enter.
- View all tasks in a clean, organized list.
- Mark tasks as completed (shown with strikethrough text).
- Undo a completed task back to active.
- Delete tasks from the list.
- Tasks update instantly on the page without any reload.
- Responsive design that works on both desktop and mobile screens.

## 📝 Note
Tasks are stored in memory using JavaScript while the page is open. Refreshing the page will reset the task list, as no backend or persistent storage was used, per the project requirements.

## ▶️ Steps to Run the Project
1. Download or clone the project folder to your computer.
2. Make sure all three files (`index.html`, `style.css`, `script.js`) are in the same folder.
3. Double-click `index.html`, or open it using any web browser (Chrome, Firefox, Edge, etc.).
4. The Task Manager will load and is ready to use — no installation or setup required.
